# 🎵 Music Genre Classification System

An end-to-end Machine Learning project that classifies music tracks into different genres using audio features and multiple classification algorithms.

---

## 🧠 Project Overview

This project focuses on building a **music genre classification system** using machine learning techniques.  
It analyzes numerical audio features and predicts the genre of a song based on its characteristics.

The system compares multiple models to find the best-performing classifier.

---

## 🚀 Features

- 📊 Data preprocessing and feature scaling
- ⚖️ Feature normalization using StandardScaler
- 🤖 Multiple Machine Learning models:
  - Logistic Regression
  - Decision Tree
  - Support Vector Machine (SVM)
  - Random Forest
  - AdaBoost
  - Naive Bayes
- 🔍 Model tuning using GridSearchCV
- 📈 Model evaluation using accuracy score
- 🔄 Cross-validation for robust performance estimation
- 📉 Confusion matrix visualization

---

## 🏗️ Workflow

1. Load dataset using Pandas  
2. Explore and analyze audio features  
3. Preprocess and scale features using StandardScaler  
4. Split data into training and testing sets  
5. Train multiple machine learning models  
6. Tune models using GridSearchCV  
7. Evaluate performance using accuracy and confusion matrix  
8. Compare models using cross-validation  

---

## 🤖 Machine Learning Models

| Model | Description |
|------|-------------|
| Logistic Regression | Linear baseline classifier |
| Decision Tree | Tree-based model for interpretable decisions |
| SVM | Powerful classifier for complex boundaries |
| Random Forest | Ensemble learning model |
| AdaBoost | Boosting-based ensemble model |
| Naive Bayes | Probabilistic classifier |
